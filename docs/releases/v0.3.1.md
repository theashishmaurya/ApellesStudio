**A fix for v0.3.0, which would not start.** If you downloaded v0.3.0, replace it with this build.

**Install guide (please read first): https://apelles.studio/install/**

## What happened

v0.3.0 crashed at startup, on every Mac, before it drew a window — so it looked like nothing happened when you opened it. There was no error dialog and no crash report, which made it hard to even tell that it had failed.

The cause was a half-finished feature: an in-app updater was wired in, but without the configuration it needs, and the app refused to start rather than start without it. It is removed in this build and will come back fully configured, and actually launched before release, in a later version.

Our checks did not catch it because none of them ran the app. It compiled, its tests passed, the bundle was verified file by file and the installer was built and checksummed — all of which a program that dies on launch can pass. The release process now starts the built app and fails if it does not come up.

**v0.3.0 is withdrawn. Nothing in it is worth keeping over this build** — the two are identical apart from the fix.

## Download

`Apelles_0.3.1_aarch64.dmg` below. It needs a Mac with **Apple Silicon (M1 or later)** and **macOS 13 or later**.

The app is signed but not yet **notarized** by Apple, so the first time you open it macOS shows *"Apelles" Not Opened*. Click **Done**, then **System Settings → Privacy & Security → Open Anyway**. You only do this once per download. The install guide has screenshots and a one-line Terminal alternative.

Your projects are not touched by any of this.

## Everything in v0.3.0

This build is v0.3.0 plus the startup fix, so it is also the **first release with Motion**. The full notes are in [v0.3.0](https://github.com/theashishmaurya/ApellesStudio/releases/tag/v0.3.0); in brief:

- **Motion ships** — scenes, layers, keyframes with real easing, 2D and 3D cameras, templates and themes, with its render runtime downloaded on first use.
- **The editor, redesigned** — a four-tab Inspector in real units, a graph-driven EQ, rebuilt Export / Music edits / Clipper panels, and `Cmd+D` to duplicate a clip.
- **Much faster** — one GPU engine paints preview and export, decode and encode run in-process on VideoToolbox (a 60 s 4K export takes about 29 seconds), and opening a large project went from about 12 seconds to under 3.
- **Brand kits, beat-synced editing, platform safe-area guides, Hide from Screen Capture**, and a Settings gear that is actually reachable.

## Known limits

- **macOS on Apple Silicon only**, macOS 13 or later.
- **Not notarized yet** (see above).
- **No automatic updates.** This build cannot update itself; new versions are downloaded here.
- **A rare stall on very large timelines.** On about 300 clips, dragging a clip can occasionally freeze the window for a couple of minutes before recovering on its own. Reproduced roughly once in 130 attempts; nothing is lost when it happens.
- Transcription is tested on English. Hindi and Hinglish are not supported.
- Motion renders are not yet bit-identical run to run (the individual frames are).
